# Security policy

This contract has **not** been externally audited.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private vulnerability
reporting ("Security" tab → "Report a vulnerability") on this repository.
Include affected version, a minimal reproduction, and impact. You will get an
acknowledgement within 5 days.

## Scope

In scope: the contract in `crates/splitter`, CI workflows, and the demo script.
Out of scope: third-party tokens, the Stellar network itself, and issues
already listed in `docs/KNOWN-LIMITATIONS.md`.
